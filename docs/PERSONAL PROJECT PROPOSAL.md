# Personal Project Proposal

## Inventory Accuracy & Stock Performance Analysis

**Project type:** Personal Data Analytics Project  
**Primary tool:** Microsoft Excel  
**Supporting tools:** Git & GitHub  
**Dataset:** Publicly available Kaggle inventory/supply-chain dataset

## 1. Project Overview

This project focuses on analysing inventory and warehouse data to identify stock risks, inventory performance patterns and opportunities to improve inventory control.

Microsoft Excel will be used to prepare, clean, validate and analyse the dataset, develop KPIs, create PivotTables and build an interactive dashboard. Git and GitHub will be used for version control, documentation and project publication.

The dataset is publicly available and does not represent actual DHL operational data.

## 2. Main Question

How can inventory data be analysed to identify stock risks, warehouse performance issues and opportunities to improve inventory control?

## 3. Project Aim

To develop an Excel-based inventory analysis and reporting solution that identifies inventory performance trends, potential stock risks and areas for operational improvement.

## 4. Objectives

The project will:

1. Obtain and prepare the Kaggle dataset.
2. Profile the dataset and assess data quality.
3. Clean and standardise the data.
4. Validate inventory-related fields and records.
5. Create relevant inventory calculations and analytical measures.
6. Analyse inventory performance by SKU, product/category and warehouse where supported.
7. Identify potential stock-risk areas.
8. Analyse demand and inventory trends.
9. Develop relevant inventory KPIs.
10. Create PivotTables and PivotCharts.
11. Build an interactive Excel dashboard.
12. Identify key findings and provide practical recommendations.
13. Document the methodology, assumptions and results.
14. Publish the completed project on GitHub.
